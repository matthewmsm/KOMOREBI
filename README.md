# CATHARSIS
Наш проект – AI-трекер, отслеживающий психологическое состояние студента. Мы ориентированы на русскоязычный сегмент, а нашими преимуществами являются эмпатичные, чуткие и осознанные ответы языковой модели; поддерживающие и милые карточки с КПТ-практиками, позволяющие чувствовать себя комфортно, как бы получая поддержку близкого человека.
