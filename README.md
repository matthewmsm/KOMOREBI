# KOMOREBI
Наш проект – геймифицированный ИИ-планировщик, в котором пользователь выращивает собственный уютный сад. Название отсылает к японскому слову про солнечный свет, пробивающийся сквозь листву.
Работает это так: студент пишет или наговаривает все дела одним сообщением (например, "ой, завтра контрольная по непре, ещё надо бы приготовить покушать что-нибудь, ааа мы и с подругой в 18:30 подговаривались встретиться. образ бы собрать, не знаю"), а LLM выделяет из него задачи, сроки и примерную длительность, предлагая маленькие первые шаги. Сервер проверяет ответ модели в строгой JSON-схеме, а обычный код сверяет, помещается ли план в день. Задачи становятся квестами в журнале, а выполненные действия открывают новые элементы сада. Все данные хранятся в базе, чтобы подстраивать рекомендации под конкретного человека.
